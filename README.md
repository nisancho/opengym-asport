# OpenGym A-Sport

A customized gym management and workout tracking platform developed for **Centro Deportivo A-Sport**.

This project is a real-world adaptation of the open-source **openGym** project, extended with new authentication, administration, body-composition tracking and deployment features for use in a family-run gym.

## Project purpose

The goal of this project is to provide a simple self-hosted platform where gym members can:

- access their personal profile
- follow assigned training plans
- track workouts and progress
- store body-composition measurements
- access the platform securely from different devices

The system is currently deployed on a dedicated Linux server at the gym using Docker.

## Deployment

The application runs on a dedicated Linux Mint server inside the gym.

The production setup includes:

- Dockerized frontend and backend
- Nginx reverse proxy
- Persistent local storage
- HTTPS remote access
- Automatic container restart
- Local network access for gym infrastructure

## Authentication

The original passkey-based authentication remains available, while the A-Sport version introduces a simpler username/password flow for gym members.

New users are created using invitation codes generated by an administrator.

Administrators can also reset user passwords and remove accounts directly from the admin dashboard.

## Body composition

The application supports manual measurements from equipment such as Tanita body-composition scales.

Tracked values include:

- Body weight
- Body fat percentage
- Muscle mass
- Bone mass
- BMI
- BMR
- Metabolic age
- Body water
- Visceral fat
- Body circumferences
